# Source evidence supplied by the author

This directory contains source extracts and companion metadata supplied for the atlas review, together with the source-specific notes. It is not a second final atlas. The finished 21-layer dataset is reconstructed from data/.

Source credits, terms and verification status: ../SOURCES_AND_RIGHTS.md. File identities and sizes are recorded in INVENTORY.csv; a Git blob SHA is an object identifier, not a standalone file SHA-256.

- wind/: technical identity of the supplied two-band 1-km raster; the raw file is withheld until its original catalogue record and redistribution terms are identified.
- lgl/: DGM1/nDOM1 companions, tile inventories and licence evidence; no full terrain raster mosaic.
- noise/: supplied road, rail and industrial noise polygon extracts.
- osm/: supplied OSM extracts and Geofabrik source package.
- bfrk/: supplied accessibility infrastructure CSV exports.
- boundary/: supplied Stuttgart administrative-boundary extract.
- symbols/: copies of the replacement geometric SVGs used by this public snapshot.

The source-specific licences continue to apply. Do not assume that all inputs share one observation date, or that current catalogue metadata exactly identifies a historical export. Do not upload credentials or private correspondence. The local ZIP builder excludes this source-evidence directory; its normal output contains the finished atlas and reviewed documentation.
