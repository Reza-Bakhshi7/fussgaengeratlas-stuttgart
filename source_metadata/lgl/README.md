# LGL DGM1 / nDOM1 evidence

The author supplied DGM1.zip containing 300 raster `.tif.aux.xml` companion files. Their filenames identify DGM1 tiles and the year 2023; the full TIFF rasters are not included here. These auxiliary files mainly contain statistics, not complete licence metadata.

nDOM1.zip contains 296 CSV companions plus a licence PDF and a metadata-record URL. The exact companion filenames are listed in the separate inventory CSVs. A tile label does not establish the download date or prove which tiles were consumed by a particular run.

The supplied LGL licence PDF specifies Datenlizenz Deutschland – Namensnennung – Version 2.0 (dl-de/by-2-0), with this provider credit: “Datenquelle: LGL, www.lgl-bw.de, dl-de/by-2-0”. Retain the dataset URI and mark modifications. A standalone copy is in ../../LICENSES/LGL_dl-de_by_2_0.pdf.

nDOM1 metadata record: https://metadaten.geoportal-bw.de/geonetwork/srv/api/records/ee4b57ee-9354-473a-857e-2a34642e52e7/formatters/xsl-view?output=pdf&language=ger&approved=true . General product portal: https://www.lgl-bw.de/Produkte/Open-Data/ .

Atlas processing used these sources for endpoint elevation and object-height estimates. This repository does not claim the companions alone reproduce the terrain model. Exact original raster hashes and processing-run linkage remain provenance details to complete.
