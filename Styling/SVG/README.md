# Geometric symbols — 27 October 2026

The eleven SVG files in this folder were newly constructed from simple geometric paths for this public snapshot. They contain no imported third-party SVG paths, raster tracing or external assets. Existing filenames are retained so the QGIS project and embedded/external style references continue to resolve.

These newly created geometric symbols are supplied under CC0 1.0 Universal: https://creativecommons.org/publicdomain/zero/1.0/ . This notice applies only to these new symbols, not to the atlas database, source data, QML or documentation.

The earlier private preparation used symbols from several sources, including Icons8 and JOSM. The Icons8 original-file redistribution restriction was incompatible with shipping that SVG as a downloadable asset. The public snapshot therefore uses the new symbols throughout; duplicated symbol files in source_metadata/symbols match this folder.

The historical JOSM curb symbols were identified as Jeroen Hoek’s kerb-raised.svg and kerb-lowered.svg from https://josm.openstreetmap.de/wiki/Styles/SidewalksAndFootways . They are credited here for provenance of the earlier working edition, not used as geometry in the replacement files.
