# Method review and limits — 26 October 2026

These findings concern supplied historical code. Without the exact inputs and execution record, they do not prove which revision generated every final value. The delivered database has not been numerically modified by this review.

1. **Solar time approximation.** The summer/winter solar helpers derive hour angle from UTC, without an explicit longitude correction or equation of time. Their civil-time labels are approximate; do not claim astronomically validated shadow positions. The summer UTCI calculation also uses a separate fixed elevation list. Verify timing and recompute in a new edition if precise time comparisons are required.
2. **Mean shade reused in UTCI.** Historical UTCI scripts use each segment's mean shade fraction at every model time, with a simplified mean-radiant-temperature formula. This is not the same as an hourly radiation calculation followed by averaging. Constant weather inputs describe project scenarios; the supplied records do not substantiate the comments claiming DWD 95th/5th percentiles.
3. **Wind interpretation.** The wind index uses min/max normalisation, a perpendicular-alignment heuristic, a mean-elevation difference (not a standard local-window TPI), and building coverage. Weights and physical interpretation have not been independently calibrated. The raster sampler assumes compatible coordinates and an axis-aligned affine grid; verify CRS, bands, nodata and metadata before rerunning. Geometry exceptions can fall back to zero building coverage. The original raster's publisher, units, period and licence remain unresolved.
4. **Tree-parameter variants.** The standalone tree script uses a 15-metre maximum crown search and 0.5 threshold, whereas the combined summer script has an 8-pixel limit and 0.3 threshold. These are not interchangeable. Determine the exact production branch before claiming full reproducibility. Winter exclusion of all tree shadows is a simplifying assumption, including for evergreen trees. The 9-metre fallback building height is a project assumption, not a verified DIN rule.
5. **Slope.** The final package contains 138 values above 60%, maximum 4095.16%. Do not silently cap these or describe them as plausible walking gradients. Resolve source/geometry anomalies in a separate data revision and preserve the current documented edition.
6. **Noise.** The historical join uses segment centroids, the maximum overlapping value per source and logarithmic summation. Confirm the exact source indicator: a filename containing `tag` alone does not establish LDEN. Missing assignments labelled `quiet` do not demonstrate quiet conditions. Combining sources is an atlas-derived result.
7. **Class and version differences.** Historical files use German class strings and earlier network sizes. The final field specification and delivered database govern the current schema. Surface material classes do not establish maintenance condition or complete accessibility.

A clean executable reproduction pipeline would need explicit input paths, validated metadata, a fixed environment, ordered processing stages, backups, output-version guards and comparison against the delivered database. That is separate work from publishing the atlas as an analytical dataset.
