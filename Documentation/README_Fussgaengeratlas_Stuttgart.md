# Supplied atlas delivery

The delivered atlas is documented as dated 15 September 2026. Follow the root README to reconstruct the GeoPackage and open the QGIS project.

This repository contains the QGZ project, compressed lossless database, 21 external QML styles, 11 SVG symbols, main documentation, source register and current QA report. No terrain raster is included. Old build-log output and a stale historical manifest were removed from the current publication tree; use the root MANIFEST_SHA256.txt instead. This preparation does not refresh the underlying data.
