# Reproduction scope

## Use the atlas

The QGZ, reconstructed GPKG, QML/SVG files, user documentation, source register and checksums reproduce the delivered analytical dataset and map configuration. Intermediate processing layers are not required for opening it. The local ZIP builder produces an ordinary archive containing the restored database.

## Source evidence

The source_metadata directory contains the extracts and companion metadata supplied by the author. DGM1/nDOM1 raster tiles themselves are not included. The LGL inventories identify the supplied companion filenames; exact consumed input files, hashes and final processing-run linkage are not established solely by those lists.

The supplied OSM roads ZIP contains a DBF attribute table only, without matching shapefile geometry components. The wind raw raster is withheld pending source identification. These supplied materials therefore do not constitute a complete upstream rebuild kit.

## Methods

Nine redacted historical reference snapshots describe the principal processing methods. They are readable .py.txt files, not a supported executable pipeline. Earlier counts, layer names and parameter variants must be distinguished from the final edition. Exact environment versions, ordered final script revisions and all input snapshots remain necessary for a full independent recomputation.
