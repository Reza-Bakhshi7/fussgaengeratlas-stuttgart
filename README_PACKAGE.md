# Pedestrian Atlas Stuttgart — QGIS delivery

Extract this entire folder and open Fussgaengeratlas_Stuttgart.qgz in QGIS. Keep the GeoPackage and Styling directory beside the project. A ZIP produced with tools/build_release.py already contains the restored database; no Python restoration step is needed for that ZIP.

Dataset processing status: 15 September 2026. Public packaging review: 27 October 2026. No DGM1 raster is included or required for the supplied project. The online OSM basemap requires internet.

Read SOURCES_AND_RIGHTS.md and Documentation/PUBLICATION_REVIEW.md for source-specific reuse terms, scientific limits and review scope. The methods directory contains historical reference text, not an executable reproduction pipeline. Zenodo archiving and a DOI are deferred.

Related app: https://sonnenpfad-stuttgart.de/
